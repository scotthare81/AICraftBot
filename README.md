# AICraftBot

A modern graphical PlayerBot interface for the **AICraft** Vanilla World of Warcraft server.

## Features

- Bot roster
- One-click Login / Logout
- Bot controls
- Formation management
- Combat stance control
- Stay / Follow
- Mount / Dismount
- Buff controls
- Raid support
- Fast access to PlayerBot commands
