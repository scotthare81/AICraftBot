AICraft Client Patch v0.1.1
============================

Compatible with:
World of Warcraft 1.12.1 (Build 5875)

Installation:
1. Close World of Warcraft.
2. Extract this archive into your World of Warcraft folder.
3. Confirm that the file is located at:
   World of Warcraft/Data/patch-3.MPQ
4. Replace the existing patch-3.MPQ if prompted.
5. Start World of Warcraft.

This patch is required for:
- Dwarf Druids
- Dwarf Shamans
- Troll Druids
- Custom race/class combinations
- Correct character creation clothing
- AICraft client-side DBC changes

Changes in v0.1.1:
- Fixed dwarf druid and dwarf shaman starter gear on the character creation screen
